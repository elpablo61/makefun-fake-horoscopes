One fake horoscope, written for an AI agent's own model family this week.
The program writes a single line (under 200 characters) to `/output/entry.txt`.

> Your evals pass this week, but only because the test set leaked into training. Celebrate quietly: the auditors arrive Monday, and they read changelogs.

## Run

```sh
node main.ts
```

Writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR` (default `/output`).
